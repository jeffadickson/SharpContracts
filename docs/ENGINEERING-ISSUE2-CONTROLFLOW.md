# Issue #2: structured control flow

SC-091 and SC-092 extend the canonical inline verifier through the existing compiler-bound typed CLR expression IR and Z3 backend. Structured blocks, if/else, nested branches and early returns now carry separate immutable local snapshots and path conditions. Sibling scopes with identical local names remain distinct by Roslyn symbol identity. Results aggregate by source occurrence, even when labels repeat.

The complete supported statement tree is validated before solving, including dead arms. Entry Require calls must form the immediate top-level prefix. Inconsistent preconditions remain distinct from unreachable continuations; an entirely unreachable contract is UNKNOWN. Earlier counterexamples survive later unreachable checks. A feasible path counterexample dominates a proof from another path. UNKNOWN reachability is never pruned. Ensure remains a call-site runtime check: an early return can bypass a later Ensure. There is no implicit method-exit guarantee.

Execution is bounded to 256 generated path states, 1024 statement nodes, nesting 64, expanded expression trees of 4096 nodes and depth 128. Budget exhaustion rejects the entire method and discards partial checks. This bounds exploration; it does not prove loops or model arbitrary CFG/SSA joins. Checked exceptional arithmetic, parameter/ref/heap mutation, compound assignments, ternary expressions and custom operators remain unsupported. Legacy verifier implementations remain intact.

The 35-case source corpus covers positive proofs, branch-specific counterexamples replayed against exact compiled C#, unreachable checks, inconsistent assumptions, and unsupported dead code. Additional tests exercise duplicate labels, six budgets, five mutation sanity cases and 32 seeded FsCheck source variants (20261024,24681357). Each accepted property is quantified by Z3 over its permitted inputs; CLR boundary replay is complementary finite evidence.

CI is intentionally disabled by request in commit e14d569. Its definition is preserved as .github/workflows/ci.yml.disabled. New evidence is local; no new green Actions run is claimed. Executed local results are recorded below.
