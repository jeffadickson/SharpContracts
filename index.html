SharpContracts M0

Design by Contract for C#: preconditions protect entry, postconditions define promised results, and invariants preserve object validity. This runnable browser simulation uses JavaScript, not .NET or formal proofs.

C# API sketch

Contract.Require(amount > 0, "PRE-004", "amount must be positive");
var oldFrom = Contract.Old(from.Balance);
var oldTo = Contract.Old(to.Balance);
from.Debit(amount);
to.Credit(amount);
Contract.Ensure(from.Balance == oldFrom - amount, "POST-001", "source delta");
Contract.Ensure(to.Balance == oldTo + amount, "POST-002", "destination delta");

Semantics and limitations

A failed precondition prevents entry. A failed postcondition detects a broken guarantee after mutation; this prototype does not roll back changes. C# `Old<T>` does not deep-copy referenced objects. Proof, automatic weaving, async contracts and Roslyn analyzers remain planned.
